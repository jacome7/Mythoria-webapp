# Checklist de revisão

## Página e voz

- [x] Conteúdo público em pt-PT natural, direto, quente e centrado no livro acabado.
- [x] H1, metadata e CTAs seguem o requisito aprovado.
- [x] Sem testemunhos, avaliações, urgência falsa ou alegações de cliente.
- [x] Exemplos apresentados como livros criados com a Mythoria, sem rótulo público de ficção.

## Segurança e privacidade

- [x] Risco `yellow`, conta adulta e revisão humana obrigatória.
- [x] Inputs de demonstração sintéticos, sem dados de crianças reais.
- [x] Sem promessas terapêuticas, educativas, comportamentais ou de desenvolvimento.
- [x] Analytics exclui conteúdo da história e dados pessoais.

## SEO

- [x] Uma rota canónica e cluster amplo, sem páginas doorway.
- [x] Links contextuais para intenções mais estreitas.
- [x] `indexable: true`; incluída no sitemap, hub e homepage após aprovação explícita.
- [x] Sem Product, Review ou AggregateRating.

## Media

- [x] Quinze imagens finais inspecionadas a 100%.
- [x] Títulos exatos compostos deterministicamente nas cinco capas.
- [x] Cinco MP3 tecnicamente validados e dentro do intervalo de 30–45 segundos.
- [ ] Cinco MP3 escutados integralmente por revisor editorial pt-PT.
- [x] Capa, feature e capítulo consistentes para cada livro.
